## Overview

The FAT12 file system is one of the earliest file systems introduced by Microsoft for MS-DOS. In this project, you will learn its fundamental structure and implementation by building it from the ground up.

## Features

- Written entirely in **C**.
- Provides a hands-on learning experience with low-level file system concepts.
- Step-by-step implementation to understand the functioning of FAT12.
